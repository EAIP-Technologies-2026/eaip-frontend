# Changelog — @eaip/motion

All notable changes to this project will be documented in this file.

## [0.0.0] - 2026-08-06

### Added
- Initial release of `@eaip/motion` foundation package.
- Motion duration tokens (`instant`, `micro`, `fast`, `normal`, `medium`, `slow`, `deliberate`).
- Motion easing tokens (`linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `premium`, `snappy`, `bounce`).
- Spring physics parameters (`stiffness`, `damping`, `mass`).
- `useReducedMotion` React accessibility hook.
- Primitive transition configurations (`fade`, `slide`, `scale`).
- CSS custom variables and prefers-reduced-motion media queries.
- Reference documentation for upcoming motion specifications (`card-beam`, `navbar`, `toggle`, `login`).
